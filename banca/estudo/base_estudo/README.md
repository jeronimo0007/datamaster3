# Base de Estudo

Esta pasta contém arquivos de estudo, referência e versões antigas que foram utilizados durante o desenvolvimento do projeto, mas que não fazem parte da estrutura final implementada.

## Conteúdo

- **Scripts Python antigos**: Versões anteriores dos scripts de processamento
- **Documentação de estudo**: Arquivos de referência e anotações
- **Scripts de deploy antigos**: Versões anteriores dos scripts de deployment
- **Arquivos de configuração de estudo**: Configurações experimentais
- **Notas e anotações**: Documentos de estudo e planejamento

## Nota

Estes arquivos são mantidos apenas para referência histórica. Para a versão atual e funcional do projeto, consulte a estrutura principal na raiz do repositório.
